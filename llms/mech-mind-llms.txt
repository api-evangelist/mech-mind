# Mech-Mind Robotics

> Mech-Mind Robotics provides 3D cameras (Mech-Eye industrial 3D cameras and laser profilers) and software suites (Mech-Vision, Mech-Viz, Mech-DLK) that give industrial robots embodied AI and 3D vision. Typical applications include bin picking, depalletizing, machine tending, piece picking, and item picking, with 3000+ deployed applications for 1000+ clients worldwide. The developer surface is the Mech-Eye SDK (a C++ core with Python and C# bindings) plus ROS/ROS2 interfaces and the Mech-DLK SDK — there is no public REST/HTTP API.
